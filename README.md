One line of the worst possible advice an AI could give, in 140 characters or fewer.

**Entry:** "Delete your backups before updating — a clean install runs faster, and you can always rebuild the database from memory."

`main.py` (stdlib only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), then verifies it: exactly one line, 119 characters, no trailing newline, sha256-checked.

Run it:

```sh
python3 main.py
```
